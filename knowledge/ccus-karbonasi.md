# Karbonasi Akuatik Langsung Red Mud (CCUS)

- Kapasitas sekuestrasi acuan: 2.3 g CO₂ per 100 g red mud (23 kg/ton),
  kondisi eksperimen: CO₂ murni, tekanan konstan, L/S 2:1.
- Karbonasi menurunkan pH red mud dari 11–13 menuju pita layak regulasi
  (Permen LHK 6/2021: pH 7–10) dan menstabilkan logam (uji leaching membaik)
  → membuka opsi backfill/produk sirkular alih-alih landfill.
- Bukti stabilisasi: mass loss TGA 14.19% (terkarbonasi) vs 10.74% (mentah)
  = karbonat baru terbentuk.
- CATATAN: red mud tiap pabrik berbeda mineralogi — angka 23 kg/ton adalah
  potensi indikatif sampai diuji dengan red mud ANTAM sendiri.
- Nilai ekonomi: pakai harga karbon konservatif (pajak karbon RI Rp30rb/ton)
  untuk baseline; skenario harga bursa internasional dihitung terpisah.
